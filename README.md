      🟢 Why does this exist? 🟢

🔹 In 28-31°C weather, the phone gets very hot while playing games.

🔹 As we all know, this can cause frame rates to drop and when this happens, the game may lag.

🔹 A phone cooler is the best solution.

🔹 But some games forcefully take all the CPU power, even though they can run smoothly without requiring all the CPU power.

🔹 This module is for those games.

🔹 You can limit the CPU usage to 70%, 80%, 90% and 100% by clicking the action button of the module.

🔹 Result -
Extend the heating time and play games longer.

🔹 Tip -
For daily use, using 70% of the CPU without playing games will significantly reduce the battery temperature in hot weather.

⚠️ This module only works for 8 CPU cores. 6 small cores and 2 big cores.
